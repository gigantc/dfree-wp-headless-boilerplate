# Component Folder Structure

Reusable UI atoms used across blocks and templates. Mirrors the PHP theme's
`components/` folder.

## Folder shape

```
ComponentName/
├── ComponentName.tsx           React component
└── ComponentName.module.scss   Scoped styles
```

The manifest (`components/manifest.json`) is auto-generated by
`scripts/generate-components-manifest.ts`.

## Usage

Import directly:

```tsx
import Button from "@/components/Button/Button";

<Button href="/contact" variant="primary">Contact</Button>
```

Unlike the PHP theme's `component('button', [...])` helper, JS uses native
imports. The manifest exists for tooling (dev warnings, unused-component
detection), not for the render path.
